# Templates

Full Site Editing (FSE) block templates that define complete page layouts.

## Purpose

This directory contains block-based templates that add new custom templates.

## How It Works

- **Automatic Override**: Any template here with the same filename as the parent theme automatically overrides it
- **Child Theme Priority**: WordPress automatically loads child theme templates before parent theme templates
- **New Templates**: Custom templates are automatically available in the Site Editor

## Usage

Templates are automatically detected by WordPress. Select them via:

- Site Editor (Appearance → Editor → Templates)
- Page/Post editor template selector
- WordPress template hierarchy
